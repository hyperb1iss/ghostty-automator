# Ghostty Automator v1.3.1-auto.4

The macOS installer, packager, and Homebrew launcher now use the app bundle's
actual executable name, `ghostty`. Earlier scripts used `Ghostty`, which worked
on case-insensitive filesystems but failed on case-sensitive macOS volumes.
Packaging fixtures now reproduce the lowercase executable on Linux so this
mismatch cannot hide behind a case-insensitive build host.

The Homebrew publication credential has been restored from the dedicated
1Password item. The tap formula includes the app, runtime data, and agent skill.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/hyperb1iss/ghostty-automator/automator/install.sh | bash
~/.local/bin/ghostty-automator +bootstrap
```

Agents can inspect the installation with `+doctor`, read rendered screen text,
send keyboard and mouse input, and capture PNG screenshots. The installer
includes the terminal automation skill and its Claude discovery link. No
separate MCP server or Python environment is required.

The fork retains the Ghostty 1.3.1 baseline and portable Linux CPU targets from
auto.3. Published archives include SHA256 sidecars. Linux requires host GTK
4.14+ and libadwaita 1.5+; starting a terminal requires a graphical desktop.

The macOS app is unsigned and unnotarized. Native build, package installation,
and CLI checks are covered by CI; macOS GUI automation has not been exercised.
